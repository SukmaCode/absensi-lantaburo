Design a professional authentication experience for "Homeschooling Lantaburo", consisting of Login and Register pages.

The authentication pages must feel like a natural extension of the existing Lantaburo landing page design. Do not create a generic SaaS login template or a visually disconnected authentication screen.

DESIGN CONTINUITY

The authentication experience must inherit the same visual identity as the landing page:

Primary brand color:
#41C623

Dark brand:
#246914

Supporting colors:
#E0F4FF
#FFFFFF
#F8FCFF
#172033
#64748B
#FBBF24

The visual language should remain:

* Clean contemporary education website
* Friendly but professional
* Warm and human-centered
* Spacious
* Accessible
* Modern but not overly technological
* Trustworthy for parents
* Comfortable and approachable for students

The authentication pages should immediately feel like they belong to the same website as the landing page.

TYPOGRAPHY

Use Plus Jakarta Sans.

Font weights:

* 400 Regular — body text and descriptions
* 500 Medium — labels and navigation
* 600 SemiBold — buttons and form headings
* 700 Bold — main page heading

Use strong typography hierarchy without making the interface feel heavy.

AUTHENTICATION LAYOUT

Create a two-column desktop layout.

LEFT SIDE — BRAND / VISUAL PANEL

Use the dark green brand color #246914 as the primary background.

The left panel should occupy approximately 40% of the desktop viewport.

Include:

* Lantaburo logo / wordmark
* Short brand statement
* One authentic educational photograph or subtle visual composition
* Minimal decorative shapes inspired by learning, growth, and exploration

Example messaging:

"Belajar dengan cara yang lebih personal dan bermakna."

Supporting text:

"Ruang belajar yang mendukung setiap siswa untuk berkembang sesuai potensi dan kebutuhannya."

The visual panel should feel calm and welcoming rather than corporate.

Use white typography.

Do not fill the panel with excessive illustrations or decorative elements.

RIGHT SIDE — AUTHENTICATION FORM

Use #F8FCFF as the main background.

Place the authentication form inside a spacious centered content area.

Do NOT use an oversized floating glassmorphism card.

The form should feel integrated directly into the page.

LOGIN PAGE

Include:

Small brand label:
"HOMESCHOOLING LANTABURO"

Main heading:
"Selamat Datang Kembali"

Supporting text:
"Masuk untuk melanjutkan perjalanan belajar bersama Lantaburo."

Form fields:

* Email
* Password

Additional controls:

* Remember me checkbox
* "Lupa password?" link

Primary button:
"Masuk"

Secondary navigation:
"Belum punya akun? Daftar"

REGISTER PAGE

Main heading:
"Buat Akun"

Supporting text:
"Mulai perjalanan belajar bersama Homeschooling Lantaburo."

Fields:

* Nama Lengkap
* Email
* Password
* Konfirmasi Password

Primary button:
"Daftar"

Secondary navigation:
"Sudah punya akun? Masuk"

FORM DESIGN

Input fields should use:

Background:
#FFFFFF

Border:
subtle #CBD5E1

Text:
#172033

Placeholder:
#64748B

Focus border:
#41C623

Focus ring:
very subtle green tint

Input height:
approximately 48–52px

Border radius:
10–12px

Do not use excessive rounded-pill inputs.

BUTTON DESIGN

Primary button:
Background: #41C623
Text: #FFFFFF

Hover:
Use a slightly darker green derived from #246914.

Buttons should have:

* Medium rounded corners
* Strong readable typography
* Comfortable horizontal padding
* Clear hover state
* Clear disabled state

Do not use gradients on the primary authentication button.

AUTH VISUAL LANGUAGE

Use the same design principles as the landing page:

* Generous whitespace
* Strong typography
* Minimal shadows
* Subtle borders
* Medium corner radius
* Carefully positioned decorative elements
* Strong visual hierarchy

The authentication screen should feel calm and focused.

Avoid visual noise.

DECORATIVE ELEMENTS

Use very subtle decorative elements inspired by the landing page.

Possible elements:

* Small circles
* Thin curved lines
* Simple geometric shapes
* Soft green patterns
* Very subtle educational motifs

Keep opacity low.

Do not use:

* Huge blobs
* Neon effects
* Excessive gradients
* Floating 3D objects
* Random colorful illustrations
* Excessive animation

RESPONSIVE DESIGN

Desktop:

* Two-column layout
* Approximately 40% visual panel / 60% form area

Tablet:

* Reduce visual panel width
* Preserve comfortable form spacing

Mobile:

* Hide or move the large visual panel
* Keep a small Lantaburo logo at the top
* Authentication form becomes the main focus
* Use #F8FCFF as the page background
* Maintain generous horizontal padding
* Form fields should remain comfortable to tap
* Do not simply shrink the desktop layout

ACCESSIBILITY

Ensure:

* High text contrast
* Clear form labels
* Visible focus states
* Comfortable touch targets
* Error messages are clearly distinguishable
* Password visibility toggle is available
* Form validation feedback is understandable

ERROR STATES

Design realistic validation states.

For example:

* Invalid email
* Incorrect password
* Required field
* Password mismatch
* Email already registered

Use subtle but clear error styling.

Do not rely only on red color to communicate errors.

LOADING STATE

Include a clean loading state for the primary button.

Example:
"Masuk..." / "Mendaftar..."

The loading state should not cause the layout to shift.

LOGIN / REGISTER NAVIGATION

Make switching between Login and Register easy.

Use simple text links rather than large secondary buttons.

Example:

"Belum punya akun? Daftar"

"Sudah punya akun? Masuk"

The active authentication page should remain visually dominant.

IMPORTANT DESIGN CONSTRAINTS

Do NOT create:

* Generic SaaS authentication UI
* Dark cyberpunk login screen
* Glassmorphism login card
* Excessive gradients
* Neon green effects
* Excessive rounded containers
* Huge illustrations
* Cartoon-style children graphics
* Overly childish educational visuals
* Dense dashboard-like interfaces
* Excessive shadows
* Multiple competing accent colors
* Unnecessary social login buttons unless specifically required

The final result should look like a real authentication experience for a modern Indonesian homeschooling institution.

The design should communicate:

TRUST
+
EDUCATION
+
PERSONALIZED LEARNING
+
WARMTH
+
SIMPLICITY

The authentication pages must visually connect to the existing Lantaburo landing page through the same green color system, typography, spacing, photography style, border radius, and visual restraint.

Prioritize usability and brand consistency over decorative effects.
