Design a professional website for "Homeschooling Lantaburo", an alternative education institution focused on creating a supportive, inclusive, and engaging learning environment for students.

The website should feel trustworthy to parents while remaining warm, friendly, and approachable for students. Avoid the typical generic "AI education website" aesthetic. The design should feel intentionally art-directed, structured, and realistic enough to be used as a real institutional website.

DESIGN DIRECTION
- Clean contemporary educational website
- Friendly but professional
- Spacious layout with strong visual hierarchy
- Editorial-style composition rather than excessive cards
- Use large typography, generous whitespace, and carefully positioned imagery
- Rounded corners should be used selectively, not on every element
- Use subtle decorative shapes inspired by learning, growth, and exploration
- Avoid excessive gradients, glassmorphism, floating UI elements, and unnecessary animations
- Avoid excessive illustrations and stock-photo-looking compositions
- Avoid making the website look like a kindergarten website
- The overall impression should be: "a modern, trusted, human-centered education institution"

COLOR SYSTEM
Primary brand color:
#0998E8

Supporting colors:
#087BB8 — darker blue
#E0F4FF — very light blue
#FFFFFF — white
#F8FCFF — soft background
#172033 — primary text
#64748B — secondary text
#FBBF24 — small warm accent

Use #0998E8 as the main visual identity.

SECTION COLOR RHYTHM
Use alternating section backgrounds to create a strong visual rhythm:

1. Hero — #F8FCFF
2. About Lantaburo — #0998E8
3. Programs — #FFFFFF
4. Learning Approach / Benefits — #F8FCFF
5. Activities — #0998E8
6. Testimonials / Parent Stories — #FFFFFF
7. Call To Action — #0998E8
8. Footer — #172033

Do not make every section look identical. Each section should have its own composition while maintaining the same visual system.

HERO SECTION
Create a strong but simple hero.

Left side:
- Small label: "HOMESCHOOLING LANTABURO"
- Large headline communicating that education can be personal, supportive, and meaningful.
- Short supporting paragraph aimed primarily at parents.
- Primary CTA: "Kenali Lantaburo"
- Secondary CTA: "Hubungi Kami"

Right side:
- One strong authentic-looking educational image or photo composition
- Students learning in a natural environment
- Avoid cliché stock photography
- Use subtle blue decorative elements around the image

The hero should immediately communicate:
personalized education + supportive environment + student development.

ABOUT SECTION
Use a blue (#0998E8) background.

Create an editorial layout rather than a grid of cards.

Include:
- Section label
- Strong heading
- Short explanation about Lantaburo
- One supporting image
- A few simple statistics or highlights

Use white typography and very light blue supporting text.

PROGRAM SECTION
Use a white background.

Show the educational programs in a structured layout.

Do not create six identical cards.

Instead, use:
- One featured program with larger visual weight
- Two or three supporting programs
- Simple icons or small visual markers
- Clear descriptions
- Consistent spacing

The section should feel like an actual education institution's program overview.

LEARNING APPROACH SECTION
Use a soft background (#F8FCFF).

Explain how students learn and develop.

Use a horizontal or asymmetric composition with 3–4 key principles such as:
- Personalized learning
- Student development
- Practical activities
- Supportive environment

Use minimal icons and strong typography.

ACTIVITIES SECTION
Use the primary blue (#0998E8) as the section background.

Show real-world student activities through a large editorial image gallery.

Avoid a standard 3-column card grid.

Use an asymmetric gallery:
- One large featured image
- Two smaller supporting images
- Optional short captions

Images should feel authentic, human, and educational.

TESTIMONIAL SECTION
Use a white background.

Create a calm parent/student testimonial section.

Use one large featured testimonial instead of many repetitive cards.

Include:
- Quote
- Person's name
- Relationship or role
- Small profile image if appropriate

Keep the section minimal and trustworthy.

CTA SECTION
Use #0998E8.

Create a strong final message for parents who are considering Lantaburo.

Use:
- Large white heading
- Short supporting text
- White or very light button with blue text
- Optional subtle decorative educational shapes

The CTA should feel inviting rather than sales-heavy.

NAVIGATION
Create a simple sticky navigation.

Left:
- Lantaburo logo / wordmark

Center or right:
- Beranda
- Tentang
- Program
- Aktivitas
- Testimoni
- Kontak

Rightmost:
- "Hubungi Kami" CTA

Keep the navigation lightweight and uncluttered.

TYPOGRAPHY
Use a modern, highly readable sans-serif typeface.

Use clear hierarchy:
- Large expressive H1
- Strong section headings
- Medium-weight body text
- Small uppercase labels for section categories

Avoid overly playful fonts.

IMAGERY
Prioritize authentic educational photography.

Images should show:
- Students learning
- Teachers interacting with students
- Practical activities
- Collaborative learning
- Warm natural environments

Avoid:
- Generic corporate stock photos
- Overly staged smiling portraits
- Cartoon-style education illustrations
- Excessive 3D illustrations

UI DETAILS
- Border radius: medium, approximately 12–20px
- Buttons should be simple and substantial
- Use subtle borders instead of heavy shadows
- Shadows should be soft and minimal
- Use generous vertical spacing between sections
- Maintain consistent max-width content containers
- Use a 12-column desktop grid where appropriate
- Use asymmetric layouts for visual interest
- Keep visual density moderate
- Prioritize accessibility and readable contrast

RESPONSIVE DESIGN
The design must work naturally on:
- Desktop
- Tablet
- Mobile

On mobile:
- Collapse navigation into a simple menu
- Stack content logically
- Preserve image hierarchy
- Maintain generous spacing
- Do not simply shrink the desktop layout

IMPORTANT DESIGN CONSTRAINTS
Do NOT use:
- Generic SaaS dashboard layouts
- Excessive cards
- Excessive gradients
- Glassmorphism
- Neon effects
- Huge decorative blobs covering the content
- Excessive rounded containers
- Random colorful icons
- AI-generated-looking illustrations
- Overly childish visual language
- Excessive animations
- Template-like section repetition

The final design should look like a real, thoughtfully designed Indonesian homeschooling institution website: warm, credible, modern, accessible, and human-centered.

Focus on visual hierarchy, content clarity, photography, whitespace, and the strong #0998E8 brand identity rather than decorative effects.
